2. Problem Statement & Dataset Details

Problem Statement: Automated binary classification of bird images into Rooster and Pigeon categories under unconstrained real-world backgrounds using both a custom-designed Convolutional Neural Network (CNN) and a Transfer Learning model (MobileNetV2).

  • Dataset Source: Scraped from public websites and organized into two folders inside Dataset_for_CNN_model.
  • Class Counts: 4,450 Rooster images and 4,267 Pigeon images (8,717 total images; 80% Training / 20% Validation split; 0 corrupted images).
  • Preprocessing & Augmentation: RGB standardization, 224x224 resizing, pixel rescaling, RandomHorizontalFlip, RandomRotation (15%), RandomZoom (15%), and RandomContrast (10%).
  • Custom CNN Parameters: 4 Conv2D blocks (32, 64, 128, 256 filters, 3x3 kernels, same padding, ReLU, BatchNormalization, 2x2 MaxPooling) followed by Flatten, Dense (256), Dropout (0.5), and Sigmoid output (13,235,905 total parameters).
